# 開發交接

## Phase 1

- 使用 Vite、原生 JavaScript、Three.js 及 OrbitControls，提供旋轉、平移、縮放、正背面、回正和皮膚透明度。
- `src/viewer/body-model.js` 透過 GLTFLoader 和 MeshoptDecoder 載入模型，處理皮膚顯示。`src/viewer/scene.js` 負責場景與相機。`src/main.js` 串接頁面操作和載入狀態。
- GLB 由固定版本的 npm 套件提供，透過 Vite 資產匯入打包。模型署名見 [ATTRIBUTION.md](ATTRIBUTION.md)。
- 模型識別可用 `open-anatomy-3d:0.1.0:male`。原始座標為公尺、Y-up，人體前方為 +Z，人體左側為 +X。檢視器透過相機取景，保留模型原始座標。
- 目前畫面僅顯示皮膚，隱藏皮膚或把透明度調到 100% 時，模型會從畫面消失。

## 啟動與驗證

- `npm install` 安裝固定版本的相依套件及模型。
- `npm run dev` 啟動本機開發伺服器。
- `npm run build` 打包至 `dist/`。建置成功，Vite 提示 JavaScript bundle 超過預設 500 kB 門檻。
- 已以 GLTFLoader 和 MeshoptDecoder 實際解碼男性 GLB，確認皮膚、骨骼、肌肉、器官、血管和神經六個頂層節點，以及皮膚網格的有效範圍。
- 已在無介面 Chrome 驗證 WebGL 畫布啟動、模型載入完成，並觸發視角按鈕、透明度滑桿與皮膚開關。滑鼠拖曳和觸控手勢尚待實機操作驗證。

## Phase 2

- 手太陰肺經 LU1～LU11，顯示 22 個雙側示意點及左右體表線。支援穴名、代碼及拼音搜尋，點選後在右側顯示資訊並高亮。
- 支援左右側過濾，以及經脈線、穴位與代碼標籤的獨立開關。標籤預設關閉，方便先看模型輪廓。透明皮膚可透見背後的標記。
- JSON 在 Vite 建置時匯入。目錄、模型局部座標與路線分開保存，載入時驗證模型 ID、點數、資料欄位與雙側完整性。見 [DATA_SOURCES.md](DATA_SOURCES.md)。
- 已在無介面 Chrome 驗證穴名、代碼和拼音搜尋、清單選擇、空白結果提示及 3D 尺澤點選。右側過濾和關閉穴位時，無法點選被隱藏的左側標記。

## 三條經脈

- 加入手厥陰心包經 PC1～PC9 與手少陰心經 HT1～HT9。三條經脈共有 29 筆穴位、58 個雙側標記、6 條體表路線。
- 經脈各有顏色，可單獨顯示或疊加。穴位清單與搜尋範圍跟隨已勾選的經脈。
- 已在無介面 Chrome 驗證三條經脈切換、穴名與拼音搜尋、清單選擇，以及模型上的曲澤（PC3）和少海（HT3）點選。
- 心包經的天池及胸臂轉折、心經的極泉及上臂內側，以及兩經的腕掌與指端位置均待校對。現有模型手臂靠近軀幹，腋窩標記取可見表面的近似位置。
- 經脈勾選位於左側，穴位搜尋與橫向列表位於 3D 視窗上方，列表隨版面寬度換行。
- 經脈線與穴位預設使用低彩灰色，也可切換為各經分色。點選經脈線或左側經脈名稱會固定金色高亮，最後滑過的另一條經脈使用青色。取消勾選會隱藏該經脈並清除其高亮狀態。
- 已用無介面 Chrome 驗證 3D 線條點選、雙重高亮、切換選中經脈、取消勾選與直接點穴位。

## 待探索的體內解剖

- 保留體表穴位錨點。往後可用皮膚透明度搭配肌肉、骨骼、血管及神經圖層，展示穴位周圍與下方的解剖關係。
- WHO 的穴位定位以體表地標為基準。骨度分寸（B-cun）依指定的人體區段按比例量測，與針刺文獻沿進針方向描述的深度分開理解。參考 [WHO 穴位定位標準](https://iris.who.int/bitstream/handle/10665/353407/9789290613831-eng.pdf)及 [STRICTA 記錄規範](https://pmc.ncbi.nlm.nih.gov/articles/PMC3002761/)。
- 若之後製作體內示意，需區分體表錨點、模型中可辨認的組織和個別技術文獻所描述的路徑。深度本身無法指定唯一體內座標，角度、姿勢與組織厚度也會影響終點。
